# WeatherMap Application

## Description
  WeatherMap Application is a SPA for location-based weather and weather forecasts, It allows visitors to see current weather and weather forecasts for specified cities supported by google map view and share this weather state with their beloved ones threw their their beloved social platforms.
## technical Info: 
  # Programming Language
    - HTML ,CSS ,and JScript
  # APIs:
    - Geolocation
    - Open Weather
    - Google Maps
    - Share (native)
    - XHTTPRequest (native)
## How It Works:
  - type a city name in the search box and click get weather button current city weather and weather forecasts
  - whe button clicked you can share the weather data with your beloved one threw your beloved platforms.
